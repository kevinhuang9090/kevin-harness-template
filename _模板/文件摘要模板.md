> **[给 AI]** 本文件是**抄骨架用的**，不是知识库内容。

```

```

## 摘要怎么写

**要写的**：核心结论、关键判断、这份文件独有的东西。

**不要写的**：
- "本文介绍了……" 这种目录式摘要，等于没写
- 复述标题
- 泛泛的领域背景

**自测**：把摘要单独拿出来给人看，TA 能不能判断"这份要不要读全文"。
不能，就是没写好。

## 为什么强制要求

渐进式加载三级漏斗的第二级就靠它：

```
_INDEX.md（一句话）→ 摘要区块（3-5 句）→ 全文
```

没有摘要区块，AI 判断相关性只能读全文，漏斗塌成两级，
知识库一大上下文就爆。这个区块是整套加载机制的物理基础。

## 来源字段的意义

来源不是元数据洁癖，是**可信度标签**：

- `self-` 的内容 AI 可以直接当你的立场引用
- `ext-` 的内容引用时必须标出处
- `ai-` 的内容要留个心眼，可能是模型编的

来源混淆之后，AI 会把别人的观点当成你的观点讲出去。这个事故很难发现。
