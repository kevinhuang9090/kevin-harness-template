# 数字孪生知识库 · 骨架模板

把你脑子里的判断、项目经验、工作现场，整理成一个 **AI 能读懂、能接着干** 的个人知识库。这是一套**目录约定 + 渐进式加载 + 收尾回写**的方法论骨架，不含任何真实内容——clone 下来按模板填你自己的。

## 为什么要有它

每次换一个新对话、换一个 AI 客户端，AI 都从零开始，不知道你是谁、上次做到哪、你的项目长什么样。这个库给 AI 一个固定的入口和约定：

- **起手**：读 `SOUL.md`（我是谁）→ `CLAUDE.md`（怎么干活）→ `03-Current/`（上次做到哪）。
- **按需加载**：每个目录有 `_INDEX.md`，AI 先读索引判断相关性，再读摘要，最后才读全文——三级漏斗，不把上下文一次性撑爆。
- **收尾回写**：有实质进展时把"工作现场"写回 `03-Current/`，下个对话无缝接上。

## 目录约定

| 目录 | 放什么 |
|------|--------|
| 01-Me | 个人档案、判断标准、文风 |
| 02-Network | 人脉关系库 |
| 03-Current | 当前状态、工作现场（**必留**） |
| 04-Projects | 项目档案，一项目一文件夹 |
| 05-Prompts | 复用的提示词 |
| 06-Development | 开发方法论与规范 |
| 07-Knowledge | 外部知识与可复用手册 |
| 08-Insights | 自己的观点与方法论 |
| 09-Tools | 自建小工具 |
| 10-Agent-Skills | 可分享的 Agent Skill |
| 11-AI-Diary | AI 的日记 |
| 12-Products | 自有产品线 |
| 13-Evolution | 笔记繁殖实验区（沙盒） |

> 序号可不连续，目录可删；删了同步删根 `_INDEX.md` 对应行。用不上的整个目录删掉是完全正当的选择。

## 文件命名前缀

`self-`（自己的思考） `chat-`（AI 对话沉淀） `ai-`（AI 提供的知识） `ext-`（外部输入） `ref-`（参考数据）。日期后缀 `-YYYY-MM` 或 `-YYYY-MM-DD`。

## 怎么用

1. Clone 到本地，把它作为 AI 客户端（Claude Code / Codex 等）的工作目录或全局记忆目录。
2. 从 `SOUL.md`、`CLAUDE.md` 开始，把占位符 `{{...}}` 换成你自己的。
3. 建新目录/文件时，去 `_模板/` 抄骨架。
4. 真正用顺之后，`_模板/` 可以删掉。

## ⚠️ 隐私与安全（务必读）

这是**公开**骨架仓，所以不含任何真实信息。当你照它建**自己的**库时：

- **凭证永不进库**：密码、API Key、令牌、私钥一律放库外或加密。
- **第三方个人信息要克制**：同事、家人、朋友的真名和私事，不进任何会公开的地方。
- **真要上传 GitHub**：个人/工作库**默认私有仓**；公开前务必脱敏（真实 IP、域名、主机名、人名换占位符），并用 `gitleaks` 扫一遍。**git 历史是永久的——秘密一旦提交就当已泄露，要先换掉再清历史。**
